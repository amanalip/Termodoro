Why Developers Choose Termodoro

Built from scratch in safe, modern Rust to deliver the cleanest terminal productivity experience with zero distractions.

⚡

Sub-10ms Startup & Minimal RAM

Compiled directly to native machine code with Ratatui and Crossterm. Launches instantaneously in under 10 milliseconds and consumes under 15MB RAM.

🛡️

100% Offline & Zero Telemetry

Your tasks, analytics, and preferences are stored strictly on your local disk adhering to XDG standards. Zero cloud dependencies, accounts, or trackers.

Quick Start

Installation & Setup

Get up and running in seconds via Cargo, source build, or multiplexer integration. 

# Install globally via Cargo from Git repository
cargo install --git https://github.com/amanalip/Termodoro.git

# Launch Termodoro from anywhere
termodoro
# 1. Clone the repository
git clone https://github.com/amanalip/Termodoro.git
cd Termodoro

# 2. Build and launch in optimized release mode
cargo run --release
# Add a popup keybinding to ~/.tmux.conf
bind-key P display-popup -E -w 75% -h 75% "termodoro"

# Or launch directly in a 30% split pane
bind-key T split-window -h -p 30 "termodoro"
# Run Termodoro in a floating window in Zellij
zellij run --floating --width 70% --height 70% -- termodoro

Ergonomic Keybindings Reference

Vim-inspired shortcuts designed for speed and zero mouse dependence.

Key / Shortcut Action Description Context
Space Toggle Start / Pause timer countdown Global / Timer
r Reset current interval to initial duration Timer
s Skip current interval phase immediately Timer
1 / 2 / 3 / 4 Switch between Timer, Tasks, Stats, and Settings tabs Global
Tab / BackTab Cycle forward / backward through tabs Global
j / k (or ↓ / ↑) Navigate up / down through list rows Tasks / Settings
a Open Add Task dialog modal Tasks
d / x Delete highlighted task from backlog Tasks
Enter Toggle task completion or bind active target goal Tasks
f Cycle task status filter (All → Pending → Completed) Tasks
h / l (or ← / →) Adjust interval duration or switch active theme Settings
? Open keyboard shortcuts reference modal Global
q / Ctrl+C Safely persist state and quit application Global
