📦 Installation & Environment Setup

What are the system requirements to run Termodoro?

Termodoro is a single, statically-compiled native binary with zero runtime dependencies. It runs on:

  • Linux: x86_64, aarch64 (glibc or musl).
  • macOS: macOS 11+ (Apple Silicon M1/M2/M3 & Intel).
  • Windows: Windows 10/11 (Command Prompt, PowerShell, or Windows Terminal).
  • Terminal Emulators: Any terminal with ANSI TrueColor support (Alacritty, Kitty, WezTerm, KDE Konsole, GNOME Terminal, iTerm2, Ghostty).
How do I install Termodoro globally on my machine?

The fastest way is installing via Rust's official package manager, Cargo:

cargo install --git https://github.com/amanalip/Termodoro.git

This compiles the binary and places termodoro directly in your ~/.cargo/bin directory.

How do I ensure termodoro can be launched from anywhere in my shell?

Make sure Cargo's binary directory is in your shell's PATH. Add this line to your ~/.bashrc or ~/.zshrc:

export PATH="$HOME/.cargo/bin:$PATH"

Then restart your terminal or run source ~/.bashrc.

How do I update Termodoro to the latest release?

Run the cargo install command with the --force flag to recompile and replace the existing binary:

cargo install --force --git https://github.com/amanalip/Termodoro.git
How do I cleanly uninstall Termodoro and purge all stored data?

1. Remove the binary:

cargo uninstall termodoro

2. Optionally remove your local data file:

rm -rf ~/.local/share/termodoro/   # Linux
rm -rf ~/Library/Application\ Support/termodoro/   # macOS

🪟 Terminal Multiplexers & Shell Integration

How do I configure Termodoro as a floating popup in tmux?

Add the following binding to your ~/.tmux.conf to open Termodoro in a floating center modal with Prefix + P:

# Open Termodoro in a floating popup
bind-key P display-popup -E -w 75% -h 75% "termodoro"

Reload tmux with tmux source ~/.tmux.conf.

How do I run Termodoro in a Zellij floating pane?

In Zellij, you can spawn Termodoro into a floating window anytime with:

zellij run --floating --width 70% --height 70% -- termodoro
Does Termodoro work over remote SSH sessions?

Yes! Termodoro sends standard ANSI escape codes. It has zero GPU or X11/Wayland display dependencies and operates smoothly over SSH sessions.

Why do some colors look dull or incorrect in my terminal?

Ensure your terminal emulator has 24-bit TrueColor enabled. Add this to your shell profile (~/.bashrc or ~/.zshrc):

export COLORTERM=truecolor

⏱️ Timer & Pomodoro Mechanics

What is the standard interval cycle in Termodoro?

By default, Termodoro follows the classic 4-cycle Pomodoro pattern:

  1. Focus Session (25 minutes)
  2. Short Break (5 minutes)
  3. Repeat for 4 focus sessions
  4. Long Break (15 minutes)
  5. The cycle dots [● ● ● ●] reset and begin fresh.
How do I pause, reset, or skip timer phases?
  • Space: Start or Pause the countdown.
  • r: Reset the current phase back to its full initial duration.
  • s: Skip directly to the next phase (e.g. skip break and return to focus).
Can I customize focus and break lengths?

Yes. Navigate to Settings (4 or Tab). You can customize:

  • Focus Duration: 1 to 120 minutes
  • Short Break Duration: 1 to 60 minutes
  • Long Break Duration: 1 to 90 minutes
  • Long Break Interval: 1 to 24 cycles

Use h / l or ← / → to adjust values in real time.

Can Termodoro automatically start breaks and work sessions?

Yes. In the Settings screen, toggle Auto-Start Breaks and Auto-Start Work by highlighting them and pressing Space or Enter.

🎯 Task Management & Target Tracking

How do I bind a specific task to my current focus session?

1. Switch to the Tasks tab (2).
2. Highlight the task with j / k.
3. Press t to mark it with the 🎯 ACTIVE target badge.
4. Switch back to Timer (1). The active task card will display your task name and live tally!

How do estimated Pomodoro tallies work?

When creating a task with a, set your estimated Pomodoros (1–20). As you finish focus sessions with that task active, Termodoro automatically increments the completed tally (e.g. [■■□□] 2/4 🍅).

How do I filter between All, Pending, and Completed tasks?

On the Tasks screen (2), use the numeric keys:

  • 1: All Tasks
  • 2: Pending Tasks Only
  • 3: Completed Tasks Only
Is there a limit on how many tasks I can store?

There is no practical limit. Tasks are indexed with UUIDv4 and saved as compact JSON. The storage engine has been benchmarked with thousands of items with sub-millisecond save and load times.

🔔 In-Memory Audio Engine & Notifications

How does Termodoro generate sound without MP3 files?

Termodoro's audio subsystem (src/audio.rs) synthesizes 16-bit PCM RIFF WAV audio purely through mathematical sine wave functions in memory. It synthesizes:

  • Focus End: 528 Hz Zen Bowl with harmonic overtones (1056 Hz, 1584 Hz).
  • Short Break End: Upward melodic chime from D5 (587.33 Hz) to A5 (880 Hz).
  • Long Break End: Celebratory major triad arpeggio (C5 → E5 → G5).
What happens if I'm on a headless server or have no audio device?

Termodoro gracefully handles missing audio hardware without crashing. If Rodio cannot initialize an audio output stream, it falls back to the ASCII terminal bell (\x07). You can also disable sound in Settings → Sound / Bell Alert.

How do native desktop notifications work?

Termodoro utilizes notify-rust to send cross-platform OS notifications (Linux D-Bus notification daemons, macOS Notification Center, and Windows Toast system).

🔒 Data Storage, Privacy & Architecture

Where is my data stored on disk?

Data is stored locally adhering to XDG standards:

  • Linux: ~/.local/share/termodoro/data.json
  • macOS: ~/Library/Application Support/termodoro/data.json
  • Windows: %APPDATA%\termodoro\data.json
Does Termodoro collect telemetry or analytics?

Zero. There is no internet connection, no analytics SDK, no crash reporting daemons, and zero network calls. Your data never leaves your computer.

How are streaks and daily stats calculated?

Each completed focus session records a timestamped entry. Streaks track consecutive calendar days with at least one completed session, automatically handling midnight calendar rollovers and leap years.

Why is Termodoro built with Pure Rust & Ratatui instead of web technologies?

Electron and browser-based timers consume 200MB–500MB of RAM and drain battery. By using Rust and Ratatui, Termodoro launches in 5 milliseconds, consumes only 4.6MB of RAM, uses 0% CPU when idle, and guarantees memory safety without garbage collection pauses.
